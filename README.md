dette er et lite prosjekt for WES120v.
prosjektet vi skal gjøre inneholder en enkel html side og det å ta i bruk Vite

## Installasjon

node.js pnpm må være installert

Installer prosjektets avhengigheter med: 

pnpm install

## Oppstart

start serveren med:

pnpm dev

du kan nå åpne siden på adressen Vite viser deg
